# Global Technical Debt Register

This file tracks cross-cutting technical debt items that are not specific to a single feature spec. Feature-specific debt should be tracked in the respective `.kiro/specs/{feature-name}/technical-debt.md` file.

## Format Reference

| Field | Description |
|-------|-------------|
| ID | Sequential identifier (TD-001, TD-002, etc.) |
| Date Identified | YYYY-MM-DD |
| Category | Code Quality, Architecture, Security, Performance, Testing, Documentation, Infrastructure, Dependencies |
| Severity | Critical / High / Medium / Low |
| Description | What the debt is and why it exists |
| Impact | Consequences of not addressing it |
| Remediation | Suggested fix approach |
| Related Task | Spec task or context that surfaced this debt |
| Status | Open / In Progress / Resolved |
